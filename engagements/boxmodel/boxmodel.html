Questions

What is the difference between block tags and inline tags?

Block tags start on a new line and usually take up the full width while inline tags stay on the same line and take up only the space they need.

What is the margin, border, and padding?

Margin is the space outside an element. Border is the line around an element and padding is the space between the content and the border.

What are units of measurement you can use in CSS?

Common CSS units of measurement include pixels, percentages, em, rem, inches and centimeters.

When would you use a figure tag?

You use the figure tag to group an image, diagram, or other content with an optional caption using the figcaption tag.
