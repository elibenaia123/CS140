List out the different ways to select an item?

Tag Selector,ID Selector and Class Selector

What is the difference between ID and Class?

ID is unique on a page and cannot be used on any other page whereas class can be applied to other tags repeatedly.

What is the difference between a SPAN tag and a DIV tag?

SPAN tags doesnt cause line breaks whereas DIV tags creates line breaks before and after

What is the difference between a DIV tag and a HEADER, MAIN, or FOOTER?

Functionally, absolutely nothing since they all work or act the same.
