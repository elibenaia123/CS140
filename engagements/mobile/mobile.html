Questions

Why is the viewport meta tag important?

It controls how a web page scales and displays on mobile devices, preventing the browser to shrink desktop layouts down to an unreadable size.

How can you adjust the CSS for printing?

By using the @media print

When would you want to adjust the CSS for printing?

To format documents or enhance text readability on paper.

When you select the same tag twice, and in one of them you say "flex-direction: column;" and the other says "flex-direction: row;", which one takes priority?

Flex direction row takes priority since the last command or code always override the tope codes.

Pick a website you use on your phone. Name two things it changes on mobile compared to desktop.

One difference is that the images on a mobile can be viewed by scrolling horizontally whereas on the desktop, it would be viewed verticalling. Another difference is that in mobiles, the location and opening hours are listed using texts whereas on desktops, its listed using images.

What width did you choose for your breakpoint, and why?

I used 680px because it allows my website to adjust its layout for smaller screens.
