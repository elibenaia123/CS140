According to the instructor, what is the main difference between CSS Grid and CSS Flex?

CSS Grid organizing items in rows and columns whereas CSS Flexbox aligns itemns in a row or column.

Who decides where a child goes on the page: the child or its parent? Explain using your three-column layout.

The parent decides. In my three-colum layout, CSS Grid arranges Boxes A–F into three columns, while the Kid A–D elements are arranged in a separate row. The parent’s CSS rules control how the children are positioned on the page.
