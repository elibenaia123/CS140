Questions A

When do you use a table?

Table is used when you want to organize information into rows and columns.

When do you not use a table?

Table should not be used to arrange the layout of a webpage such as creating a nav bar, putting images side by side or positioning texts.

When do you need to do extra work for table accessibility?

When a table has complex information and needs clear headings so screen readers can understand it.

Questions B

Why don't we use the border attribute?

The border attribute is old style so we use css to style since it is better and easier to change the design.

What is the easiest way to color every other row a different color?

Use the :nth-child() structural pseudo-class.

What does the value in the parentheses of your structural pseudo-class mean? Give one other value you could use and which rows it would select.

(even) means it selects every even numbered row like 2,4,6. Another value is odd, which selects every odd numbered row like 1,3,5.
