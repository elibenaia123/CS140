Questions

When do you use a table?

Table is used when you want to organize information into rows and columns.

When do you not use a table?

Table should not be used to arrange the layout of a webpage such as creating a nav bar, putting images side by side or positioning texts.

When do you need to do extra work for table accessibility?

When a table has complex information and needs clear headings so screen readers can understand it.
