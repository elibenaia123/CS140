Explain the difference between inline, embedded, and external CSS.

Inline CSS is directly inside the HTML tag and only affects that specific element. Embedded CSS is located inside a 'style' tag in the HTML 'head' and affects the entire single HTML page. External CSS is located in a completely separate .css file and affects multiple pages across the whole site.

Explain why you should only use external CSS.

It is because external css allows you to keep your styling rules completely separate from your HTML.

What is a selector used for?

Selector decides which tag gets the style properties you want by using the selector abbreviation such as p for the paragraph tags or h1 for the h1 tags.
