Explain the difference between an absolute link and a relative link. Why would you use relative links?

Absolute link is usually used when linking to another website whereas for Relative link is used when linking to another within your own website and are more usually because still work especially if you move it to a different domain.

List the 3 rules with relative links.

  1. Same folder by using the filename
  2. Go into a folder by /
  3. Go up one folder by using ../
