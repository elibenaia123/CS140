Questions A

The form tag has an "action" attribute. What does it do?

It specifies where the form data is sent when the user submits the form.

The form tag has a "method" attribute. What does it do?

It lets you declare either to using a get request or post request.

What is the difference between a "POST" and a "GET"?

POST allows you to make changes or send information to the server without displaying it in the URL. GET retrieves information and displays it in the URL.

How do you fill in a form control with a pre-set value, and how is that different from a placeholder?

Textbox uses the value attribute to fill in a default answer while placeholder is a hint that disappears when the user types. Textarea put the pre-set text between the opening and closing tags. A placeholder is a hint that disappears when the user starts typing. Select box uses the selected attribute to make an opinion selected by default. Checkbox uses the checked attribute to select a radio button by default. Radio button uses the checked attribute to select a radio button by default.

List all the form controls that HTML5 added. Which ones did you put in your form?

Form controls HTML5 added are email, url, number,range, date, time, dateline-local, month, week, color, search and tel. I did not use any of the new HTML5 input types.

Questions B

What are different ways to style your form?

Change background color and font, add borders around the form, add padding and margins, use hover effects and change width of labels.

Why does the professor like to use flex?

Because it makes it easier to organize and align the form like label and input fields.

What makes for a good mobile form?

Easy to tap on large input fields or buttons, clean design and usage of colors.
