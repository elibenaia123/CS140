Internet

The internet is a large universal set of hardware structures such as routers, cables and satelites. These hardwares are linked to a multitude of computers simultaneously.

Web

A web is a system that requires internet or data to access information on a global system. These informations include files, documents and pages on a special program called a browser.

How are the Internet and Web different?

The internet is a giant physical network that links computers globally wheres the web is just one of the ways that we can share information over that network. It's easier understood by thinking of the internet as a road connecting it to all the places in that country and the web as the cars that travel on those roads to deliver passengers.

ASCII and Unicode

ASCII and Unicode are used to change text characters into binary numbers for a computer to understand. They are digital translation systems with ASCII being an older and limited system with English characters only, whereas Unicode is more of a modern system with more languages, emojis and symbols that can be covered.

What is UTF-8

UTF-8 is one of the best ways to turn texts into computer data by using different sizes. It is efficient because it uses small pieces of data that saves a lot of space.

URL

The Uniform Resource Locator is the web address that you type into a browser to search for certain file or data. Its just like an online mailing address that provides information to exactly where you can find files on the internet.

Domain Name

Domain Name are website addresses that replaces strings or numbers making it easier for a human to read and remember.

HTTP

The Hypertext Transfer Protocol acts as a language of agreement between your browser and the website. It sends code back to your screen when a link is clicked to request a page.

HTTPS

HTTPS is the safe version of the basic system that varifies the website is real.

IP Address

The IP address is a string of number that is given to every device linked to the internet.

DNS

The Domain Name System is a system that translates human readable website names into IP addresses that can be read by the machine.

W3C Recommendations

The W3C Recommendations are the World Wide Web Consortium that creates standards on webs and guidelines to keep the internet open. They make sure that different browsers interpret the same CSS code and HTML to ensure that the websites work the right way for everyone.

XML, XHTML, HTML, HTML5

Languages that constantly evolve overtime and are used to structure data and web content. Raw data is stored and organized through the XML while HTML is used to build web pages. XHTML does the same job as HTML but is older and stricter following the XML rules, and HTML5 is what we use today and focuses on flexibility with better browser performance.
